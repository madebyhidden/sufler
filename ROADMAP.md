# Путь к версии 1.0

Суфлёр уже закрывает основной сценарий: записать созвон, поймать вопрос, собрать итог и базу знаний. До 1.0 — всё, что отделяет «работает у автора и друзей» от «можно спокойно дать незнакомому человеку».

## Обязательно для 1.0

**Доверие и установка**
- [ ] Подпись и нотаризация Apple (Developer ID): без предупреждения «не удаётся открыть» и без команд в Терминале.
- [ ] Подпись кода для Windows: без предупреждения SmartScreen.
- [ ] Установщик для Windows вместо архива: ярлык в «Пуске», удаление через «Приложения».

**Надёжность**
- [ ] Автоматические проверки версии для Mac, как уже есть для Windows: запуск, запись демо-встречи, снимки экранов на каждую сборку.
- [ ] Отчёты о сбоях с согласия пользователя: что упало и на какой версии, без содержимого встреч.
- [ ] Восстановление после сбоя во время записи: недописанная встреча и её звук не теряются.
- [ ] Проверка на долгих встречах (2–3 часа) на слабых ноутбуках: память, нагрев, скорость.

**Данные**
- [ ] Резервная копия и перенос на другой компьютер: выгрузить и загрузить всю базу одним файлом.
- [ ] «Удалить всё»: встречи, звук, модели и настройки одной кнопкой.
- [ ] Поиск по всем встречам в одном поле, а не только через чат.
- [ ] Правка расшифровки: исправить слово, склеить или разделить реплики, переназначить говорящего.

**Голоса**
- [ ] Запоминание голосов между встречами: назвали собеседника один раз — в следующий раз он подписан сам (с подтверждением, чтобы не путать похожие голоса).

**Интерфейс**
- [ ] Тёмная тема в версии для Windows.
- [ ] Значок в строке меню Mac и в трее Windows: начать запись, не открывая окно; глобальная клавиша.
- [ ] Английский интерфейс и распознавание английской речи на Windows без видеокарты.

## После 1.0

- Календарь: название встречи и участники — из события; имена сразу привязываются к голосам.
- Задачи из итогов — в Things, Todoist, Jira, Notion.
- Поиск по базе знаний не только по тексту, но и по звуку и изображениям (EmbeddingGemma 2 это умеет).
- Перевод собеседника на лету.
- Мобильное приложение для живых встреч.

## Почему поиск пока на EmbeddingGemma 1, а не 2

EmbeddingGemma 2 вышла в сентябре 2026 и запускается той же версией llama.cpp, что уже стоит в Суфлёре. Мы сравнили обе на русских запросах к фактам и документам из встреч: качество поиска одинаковое (7 из 8 запросов находят нужный фрагмент первым), по таблицам Google разница на многоязычных задачах — 61,4 против 61,2.

Переход сейчас не даёт выигрыша, но требует работы:
- все векторы в базе (встречи, документы, факты) придётся пересчитать — у моделей разные пространства;
- у второй версии похожие и непохожие тексты различаются меньше, поэтому заново подбирать пороги, по которым склеиваются факты и ищутся дубли.

Настоящие плюсы второй версии — длинный контекст (8 тысяч токенов вместо 2) и поиск по звуку и картинкам. Перейдём, когда в Суфлёре появится то, чему они нужны.
