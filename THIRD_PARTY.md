# Сторонние компоненты

Суфлёр использует открытые проекты. Спасибо их авторам.

| Компонент | Для чего | Лицензия |
|---|---|---|
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | распознавание речи на Mac | MIT |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | запуск языковых моделей | MIT |
| [FluidAudio](https://github.com/FluidInference/FluidAudio) | различение голосов на Mac | Apache-2.0 |
| [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) | распознавание речи и голоса на Windows | Apache-2.0 |
| [ONNX Runtime](https://github.com/microsoft/onnxruntime) | вычисления для sherpa-onnx | MIT |
| [Whisper.net](https://github.com/sandrohanea/whisper.net) | Whisper на Windows | MIT |
| [NAudio](https://github.com/naudio/NAudio) | захват звука на Windows | MIT |
| [Concentus](https://github.com/lostromb/concentus) | сжатие звука встреч (Opus) на Windows | BSD-3-Clause |
| [PdfPig](https://github.com/UglyToad/PdfPig) | чтение PDF на Windows | Apache-2.0 |
| [Microsoft.Data.Sqlite](https://github.com/dotnet/efcore), [SQLitePCLRaw](https://github.com/ericsink/SQLitePCL.raw) | база данных на Windows | MIT, Apache-2.0 |
| [Bouncy Castle](https://www.bouncycastle.org/) | проверка подписи обновлений на Windows | MIT |
