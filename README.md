# Суфлёр

Локальный помощник на встречах для macOS. Расшифровывает разговор, показывает последний вопрос — кому он адресован и о чём шла речь, — различает собеседников по голосу, собирает итоги и факты в базу знаний. Всё работает на вашем Mac: звук и тексты никуда не отправляются.

## Установка

1. Скачайте `Sufler-<версия>.dmg` со страницы [последнего выпуска](https://github.com/madebyhidden/sufler/releases/latest).
2. Перетащите «Суфлёр» в папку «Программы» и откройте его оттуда.
3. При первом запуске приложение скачает модели (5,6 ГБ) и попросит доступ к микрофону и звуку системы.

Нужен Mac на Apple Silicon и macOS 14.2 или новее, около 7 ГБ свободного места.

### Если macOS не даёт открыть

Приложение не подписано сертификатом Apple, поэтому при первом запуске будет предупреждение. Два способа:

- Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»;
- или одной командой в Терминале — она же помогает, если macOS пишет просто «Не удается открыть программу „Суфлёр“»:

  ```
  xattr -cr /Applications/Суфлёр.app && codesign --force --deep -s - /Applications/Суфлёр.app && open /Applications/Суфлёр.app
  ```

## Обновления

Начиная с версии 0.2 Суфлёр обновляется сам: в боковой панели появляется кнопка «Обновление», скачивается только приложение (около 40 МБ), модели и ваши встречи остаются на месте. Если у вас 0.1 — один раз поставьте свежую версию вручную.

После обновления macOS может ещё раз спросить доступ к микрофону и звуку.

## На чём работает

Whisper large-v3-turbo (распознавание речи), Gemma 4 E4B (вопросы, итоги, факты, чат), EmbeddingGemma (поиск), whisper.cpp и llama.cpp.
